# 批量图片缩放工具

纯前端图片批量缩放工具：上传一堆同比例图片，一键缩放为指定尺寸并下载。全部在浏览器本地用 Canvas 处理，不上传服务器。

🌐 在线网页（快速打开）：
https://ahh20250507.github.io/image-resizer/

## 仓库说明
- 本仓库（image-resizer-src）为私人源码仓库，用于日后修改。
- 在线网页由公开仓库 image-resizer 的 GitHub Pages 托管。

## 本地使用
直接用浏览器打开 index.html / image-resizer.html 即可。

## 修改与发布
1. 在本私人仓库修改代码。
2. 要更新在线网页时，把改动推到公开仓库 image-resizer（main 分支），GitHub Pages 会自动重新构建。
